Knots User Guide

Knots is a fast multi-language code complexity analyzer built on tree-sitter. It measures traditional complexity metrics alongside two AI-specific cost scores — AIRD (AI Reasoning Difficulty) and AICP (AI Context Pressure) — to identify which functions are genuinely expensive to modify with AI assistance.
